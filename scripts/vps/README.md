# MT5 VPS bootstrap diagnostic

This is a non-trading setup test for a Windows VPS. It installs the official MetaTrader terminal and Python integration, then checks whether Python can initialize the local terminal. It does not request broker credentials, save passwords, or place trades.

## Important: GitHub cannot use RDP credentials as a remote command

The VPS IP address and Windows Administrator/RDP password are for logging in interactively. They do not by themselves give GitHub Actions a supported way to execute commands on Windows. Do not put those details into repository files or GitHub Actions secrets for an improvised RDP login.

To have GitHub run the setup job directly on the VPS, a **self-hosted GitHub Actions runner** must first be registered on the VPS. That one-time registration step requires an administrator to open a PowerShell session on the VPS and use a short-lived runner registration token generated by GitHub. The token is temporary and must not be committed or shared.

## Option A — run the setup directly once

1. Connect to the Windows VPS using Remote Desktop.
2. Open **Windows PowerShell as Administrator**.
3. Run these commands:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
$script = Join-Path $env:TEMP 'bootstrap-mt5-vps.ps1'
Invoke-WebRequest 'https://raw.githubusercontent.com/ollywheeler-gif/crypto-opportunity-scout/vps-bootstrap-diagnostics/scripts/vps/bootstrap-mt5-vps.ps1' -OutFile $script
& $script
```

4. When it finishes, find the log folder at `C:\MT5VPS\logs`.
5. Share the contents of `ipc-diagnostic.json` and the relevant log output, after checking that no personal details appear. The script does not collect broker credentials.

## Option B — run future setup jobs from GitHub

The workflow `.github/workflows/setup-mt5-on-vps.yml` has been added on the `vps-bootstrap-diagnostics` branch. It runs only on a self-hosted Windows runner carrying the label `mt5-vps`; it will **not** run on GitHub-hosted machines or automatically log into an unregistered VPS.

After the runner is registered and connected, open the repository's **Actions** tab, select **Set up MT5 on registered VPS**, and choose **Run workflow** on branch `vps-bootstrap-diagnostics`.

Security note: a self-hosted runner can execute repository code on the VPS. Only run trusted workflows and do not enable it for untrusted pull requests. Keep broker credentials out of the bootstrap diagnostic.

## What this test establishes

- Whether the official MT5 terminal installs and launches on this Windows VPS.
- Whether the official MetaTrader5 Python package installs.
- Whether Python can initialize the terminal in standard or portable mode.
- The error code if terminal IPC still fails.

This is a diagnostic only. It does not authenticate a broker account, run a strategy, or place trades. Do not put broker passwords into GitHub files or commit them to the repository.
