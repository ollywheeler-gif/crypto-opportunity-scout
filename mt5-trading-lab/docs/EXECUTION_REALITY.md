# Free-cloud execution limits
Free source control and hosted CI can run static checks and Python unit tests within current account quotas. Hosted runners are ephemeral, not always-on servers. A persistent Windows VM capable of MT5, large tick-data optimisation, paid AI API calls, and premium data are not guaranteed free.

A valid MT5 test requires a compatible terminal and MetaEditor build, exact source hash, appropriate historical data, symbol specifications and costs, explicit tester settings, raw report, logs, and reconciliation. Python OHLC simulations must never be labelled MT5 Strategy Tester results.

Statuses: NOT_STARTED, BLOCKED_ENVIRONMENT, STATIC_CHECKS_PASSED, COMPILED, BACKTESTED, ROBUSTNESS_PASSED, REJECTED, OWNER_APPROVAL_REQUIRED. Do not change status without primary evidence.

No paid resources should be provisioned automatically. If credible MT5 tests cannot fit free resources, report the blocker rather than spending money or weakening standards.
